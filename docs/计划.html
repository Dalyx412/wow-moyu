0A已定事项

    1现状

    结论：能做。叠加层窗口里跑的就是一个普通的浏览器内核，雀魂和 PokéBonk 这类网页游戏都能直接打开。真正要选的只是“窗口怎么叠到魔兽上面”。

    1.1你现在的 WCL 叠加层是怎么做的

    你在用的是 Archon App（Warcraft Logs 官方客户端）。我查了正在运行的魔兽进程：它是用 Overwolf 的 ow-electron 框架做的，往魔兽进程里加载了 Overwolf 的叠加层模块，所以面板能直接画在游戏画面里。

    这类注入暴雪一直默许，你在国服用它也没出问题。所以“做一个差不多的”在技术上成立，风险也和 Archon 同级。但这条路有申请门槛，见 §2.2。

    1.2为什么不做成游戏内插件

    魔兽插件跑在暴雪的沙盒里，不能联网，也不能打开网页，这条路走不通。插件只能做离线的东西，比如打包好的资料、用 Lua 写的扫雷。你要玩的是现成的网页游戏，所以只能做游戏外的叠加窗口。

    2两条路线

    A 独立置顶窗口B 游戏内叠加（同 Archon）
    碰不碰魔兽进程不碰加载 Overwolf 模块，和 Archon 一样
    魔兽显示模式必须用窗口化全屏（无边框）都行
    操作小窗时键盘焦点离开魔兽，按热键切回在游戏里按热键接管鼠标键盘，再按一次还给游戏
    门槛无，今晚就能开工要先申请 Overwolf 开发者凭证
    工作量一两天做到顺手A 的工作量，再加上申请和调试叠加层

    2.1路线 A：独立置顶窗口

    一个无边框、永远置顶、可以调透明度的浏览器小窗，盖在魔兽上面。魔兽切到窗口化全屏后，看起来就和叠在游戏里差不多；正式服在这个模式下几乎不掉帧。

    关键是两个热键：一个显示/隐藏；一个切换“可操作 / 鼠标穿透”。穿透状态下，小窗只是一层半透明的画面，鼠标点下去直接点到魔兽，适合挂着看攻略。

    短板：要点小窗里的东西，焦点就离开魔兽，这时候按技能键没反应，得用热键切回去。回合制的雀魂影响不大。

    2.2路线 B：和 Archon 一样的游戏内叠加

    用同一套 Overwolf 框架，把小窗直接画进游戏画面，体验最接近“插件”。

    门槛：Overwolf 规定，就算只在自己电脑上用，开发模式也得填 Overwolf 开发者后台账号的邮箱和 API key，或者 Overwolf 发给审批通过开发者的开发密钥。少了这些，叠加层模块就不加载：程序能打开，但叠不进游戏。正式打包还要自己的代码签名证书。也就是说，得先去 Overwolf 申请开发者，要不要批、要等多久不由我们决定。来源：开发模式说明、签名说明。

    A 里网页、标签页、热键这部分代码以后可以原样搬进 B，所以先做 A 不会白做。

    3两个游戏适不适合边打边玩

    3.1雀魂

    很合适。网页版直接能跑，又是回合制，等技能冷却、跑位间隙都能出一张牌。要注意每手有出牌计时，boss 战里顾不上时可能超时被自动摸切，所以更适合友人场和休闲场，段位场慎用。登录一次就行，登录状态存在叠加窗口自己的浏览器里，和你的 Chrome 分开。

    3.2PokéBonk

    能开，但只适合打本间隙玩。它是 3D 的“幸存者”类游戏，得一直操作走位，所以只能在跑尸、等拉怪、灭团整备时玩，打 boss 时没法同时玩。

    它还会和魔兽抢显卡。小窗隐藏后，浏览器会自动停掉画面刷新，多数网页游戏这时等于暂停。但小窗显示着、只是没在操作的时候不会自动停，所以会加一个“失焦就限帧”的选项，免得拖慢魔兽。

    4第一版做什么

    小窗常驻屏幕一角，默认占四分之一屏幕、半透明，不用热键。用法：点小窗就操作小窗，点回魔兽画面就回到游戏。

    • 顶部工具栏：拖动它移动窗口，右下角拖动改大小，位置和大小都会记住；
    • 书签按钮：雀魂、PokéBonk、NGA 魔兽板块、Wowhead 中文站，点一下打开，已经开着就切过去。☆ 把当前页加进书签，右键书签删除；
    • 标签：每个打开的站一个标签，× 关闭；
    • 透明度滑块、静音按钮；
    • 收起按钮：整个窗口缩成一根小条，网页全部暂停、静音；再点一下展开回原样。这就是“快速开关”；
    • 登录状态保存；托盘图标负责显示和退出；开机不自启。

    和第 1 轮比，去掉了热键和鼠标穿透（见 §0A #2）。“失焦限帧”换成两条更好实现的：只有当前标签在跑，其他标签暂停；收起时全部暂停。

    4.1做到哪了

    自动自测 14 项过了 13 项：

    • 默认在主屏右上角、占四分之一屏幕、置顶；

    没过的一项：Wowhead 的广告一直在加载，30 秒内没停。页面本身已经能看，所以我把判断条件改成“页面能看就算”，但改完还没重跑。

    还没验证、得你来试：魔兽在前台、窗口化全屏时，小窗能不能一直盖在上面；开着 PokéBonk 时魔兽掉多少帧；雀魂能不能正常登录。

    4.2打包和启动

    平时就点桌面上的「WoW 摸鱼」。程序装在你用户目录下的 Programs\wow-moyu 里，开始菜单里也有入口。它和项目文件夹是分开的两份，所以之后重新打包，不会影响正在用的那份。

    改了代码以后，在项目里运行 npm run install-local，就会重新打包、覆盖安装、刷新快捷方式；程序开着的时候会提示你先退出。想打一个能发给别人的单文件版，就运行 npm run dist。

    代码公开在 github.com/Dalyx412/wow-moyu，暂时还没有许可证。

    注意：换了程序名后，登录状态和书签存在新的位置。之前从源码跑的那份里登过的账号，要在新程序里重新登一次。

    4.3给别人用：GitHub Release

    能做，已经发了 v0.1.0。别人打开 Release 页，下载其中一个 exe 就能用，各约 100 MB：

    • 便携版：双击就能运行，不用安装。每次启动要先解压，会慢几秒；
    • 安装版：双击后自动装到当前用户下，并建桌面和开始菜单快捷方式。之后启动快，也能在系统的「应用」里卸载。

    以后怎么发新版：改 package.json 里的版本号，提交后推一个同名标签（比如 v0.2.0）。GitHub 会在 Windows 机器上打包，自动启动一次打包好的程序，确认工具栏能加载出来，然后才发布。v0.1.0 这一遍全部通过。我还把发布出来的两个 exe 下载回来核对过：名字和版本都对。

    已知限制：exe 没有代码签名，别人第一次运行时 Windows 可能会提示“已保护你的电脑”，要点「更多信息」→「仍要运行」。Release 说明里已经写了这一步。要去掉这个提示，得买代码签名证书，一年几百到上千元。
